# Bilder

Legg de seks profilbildene i denne mappen. Anbefalt format er stående bilder i JPG eller WebP, omtrent 800 × 1000 piksler.

Oppdater deretter `src` på de seks profilbildene i `index.html`, for eksempel:

```html
<img src="images/fornavn-etternavn.webp" alt="Fornavn Etternavn">
```

De seks SVG-filene i mappen er bare midlertidige plassholdere og kan slettes når alle ekte bilder er lagt inn.
