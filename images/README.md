# Bilder

Profilbildene ligger i denne mappen. Anbefalt format er stående bilder i JPG eller WebP, omtrent 800 × 1000 piksler.

Oppdater deretter `src` på de seks profilbildene i `index.html`, for eksempel:

```html
<img src="images/fornavn-etternavn.webp" alt="Fornavn Etternavn">
```

`group-photo-v2.jpg` brukes som hovedbilde i hero-seksjonen. `amina-mustafa.jpg`, `david-rakic.jpg`, `eirik-ryger.jpg`, `fredrik-aas.jpg`, `hussein-akbar.jpg` og `simon-espe.jpg` brukes på de respektive medlemskortene.

SVG-filene i mappen er midlertidige plassholdere og kan slettes etter hvert som de resterende profilbildene blir lagt inn.
